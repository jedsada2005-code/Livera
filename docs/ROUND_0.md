# Round 0 — ขอบเขตและการตรวจ

## ขอบเขต

โครงเว็บแอปมือถือ/คอมพิวเตอร์ รูปแบบร่วม แดง–น้ำเงิน เมนู 5 ช่อง ข้อมูลสมมติ และการเตรียม GitHub Pages ตามแผนที่ตกลง

ผู้ใช้หลักคือลูกค้าวัยทำงานที่เตรียมเกษียณ กรมธรรม์เฉพาะที่ผ่าน LIVERA คลับมีทั้งพบกันจริงและออนไลน์ สุขภาพเป็นการนัดปรึกษาส่วนตัว

## ข้อมูลตัวอย่าง

เบี้ยที่บันทึกแล้ว = 180,000 + 120,000 + 24,000 = 324,000 บาท

เบี้ยตามตารางที่เหลือ = 1,620,000 + 480,000 = 2,100,000 บาท โดยไม่รวมเบี้ยสุขภาพที่ต้องทบทวนในอนาคต

ความคืบหน้าสะสมทรัพย์ 18 จาก 180 งวด = 10% เป็นความคืบหน้าการชำระ ไม่ใช่คะแนนความพร้อมเกษียณ และวันชำระครบแยกจากวันครบสัญญา

มูลค่าเวนคืนยังไม่มีข้อมูลต้นทาง จึงไม่ใส่ยอดศูนย์หรือสร้างยอดยืนยันเอง

## รายการตรวจที่ใช้

- สร้างไฟล์สำหรับเผยแพร่และตรวจ TypeScript
- เปิดหน้าหลักทั้ง 5 ผ่าน hash navigation และรีเฟรช
- ตรวจรูปแบบมือถือกว้าง 360 พิกเซล และหน้าจอคอมพิวเตอร์กว้าง 1440 พิกเซล
- ตรวจว่าไม่มีหน้าใดล้นแนวนอนในขนาดที่ทดสอบ
- ดูรายละเอียดกรมธรรม์และคำอธิบายบริการได้
- กรองกิจกรรมออนไลน์/พบกันจริงแล้วรายการตรงกับตัวกรอง
- หน้าต่างรายละเอียดเปิด ปิด และใช้ Escape ได้
- ซ่อนยอดแล้วตัวเลขเงินหลักถูกปิดบัง และการตั้งค่ายังคงอยู่หลังรีเฟรช
- เปิดโหมดตัวอักษรใหญ่และคืนค่าการตั้งค่าได้
- ตรวจข้อความผิดพลาดที่หน้าเว็บรายงาน
- ตรวจไฟล์เว็บในเส้นทางย่อยแบบเดียวกับ GitHub Pages ก่อนเผยแพร่
- ตรวจการเผยแพร่และหน้าที่เปิดจริงแยกจากผลสร้างในเครื่อง

## ข้อจำกัดตามรอบ

- ยังไม่มีธุรกรรมหรือคำขอที่ส่งไปผู้ให้บริการจริง
- ข้อมูลสาธิตกรมธรรม์อ่านอย่างเดียว การบันทึกเบี้ยอยู่รอบ 1
- Goal เป็นตัวอย่างประกอบการออกแบบ ไม่ใช่เครื่องคำนวณที่กรอกค่าได้ในรอบนี้
- การตั้งค่าการแสดงผลเก็บในเบราว์เซอร์ ไม่ได้เชื่อมข้ามอุปกรณ์
- การตรวจหน้าจอในเบราว์เซอร์ไม่ได้แทนการทดสอบกับผู้ใช้จริงหรือการรับรองการเข้าถึงทุกอุปกรณ์
