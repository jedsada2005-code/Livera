# LIVERA Round 3 — Retirement Luxury Club และ Community

## ขอบเขต

รอบนี้ต่อยอดต้นแบบเดิมสำหรับลูกค้า LIVERA ทุกช่วงวัย ใช้ธีมแดง–น้ำเงินและภาพสมจริงเดิม มีเมนูย่อยกิจกรรม Community และรายการของฉัน ผ่าน hash navigation ที่เปิดตรงและรีเฟรชได้

### กิจกรรมคลับ

- ตัวอย่างกิจกรรมเดือนพฤศจิกายน 2569 ธันวาคม 2569 และมกราคม 2570 ทั้งพบกันจริงและออนไลน์
- ค้นหา กรองรูปแบบ และกรองเฉพาะกิจกรรมที่ยังลงทะเบียนได้
- รายละเอียดสถานที่ วันเวลา กำหนดปิดรับ กำหนดการ และการเตรียมตัว
- ลงทะเบียน 1 หรือ 2 ที่นั่ง เลือก → ตรวจสรุป → ผลสำเร็จ โดยยืนยันว่าเป็นข้อมูลสาธิต
- ตรวจจำนวนที่นั่งและเวลาปิดรับจากข้อมูลล่าสุดใน transaction เดียวกับการบันทึก
- ป้องกันลงทะเบียนกิจกรรมเดิมซ้ำ และป้องกันรายการเกินจำนวนที่นั่งที่มีในต้นแบบ
- มีตัวอย่างกิจกรรมเต็มเพื่อทดสอบสถานะปิดปุ่ม ไม่มีการสร้างคิวรอที่ไม่มีผู้จัดรับเรื่อง
- รายการของฉันเก็บใบรายการสาธิต พร้อมประวัติยกเลิก ลงทะเบียนใหม่ได้หากยังเปิดรับ
- ดาวน์โหลด .ics ภาษาไทยพร้อม UID และเวลา UTC มีคำว่าสาธิตในชื่อกิจกรรม ไม่ส่งคำเชิญหรือแก้ปฏิทินจริงอัตโนมัติ
- หากยกเลิกในแอป ผู้ใช้ต้องลบ/แก้กิจกรรมในปฏิทินที่เคยนำเข้าเอง มีข้อความแจ้งก่อนยืนยันยกเลิก
- ออนไลน์มีหน้าเตรียมตัว ไม่มีลิงก์ห้องจริง ไม่มีการเปิดกล้องหรือไมโครโฟน

### Community

- 3 กลุ่ม: เตรียมเกษียณไปด้วยกัน ชีวิตดีในทุกช่วงวัย งานอดิเรกและเพื่อนใหม่
- เข้าร่วม/ออกจากกลุ่มแบบสาธิต ก่อนเขียนกระทู้หรือความคิดเห็นต้องอยู่ในกลุ่มนั้น
- อ่านและค้นหากระทู้ กรองกลุ่ม เรียงตามล่าสุดหรือจำนวนความคิดเห็น
- สร้างกระทู้ เลือกกลุ่ม กรอกหัวข้อ/เนื้อหา ดูตัวอย่าง และบันทึก
- ร่างข้อความเก็บใน sessionStorage ของแท็บ ปิดหน้าต่างแล้วกลับมาเขียนต่อได้ก่อนปิดแท็บ หากเก็บร่างไม่ได้จะแจ้ง
- หัวข้อ 5–100 ตัวอักษร เนื้อหา 10–1,500 ความคิดเห็น 2–800 รายละเอียดรายงานไม่เกิน 300
- ยืนยันว่าเป็นข้อความตัวอย่าง ไม่มีข้อมูลส่วนตัวก่อนบันทึกกระทู้/ความคิดเห็น
- แสดงข้อความผ่าน React text ไม่แปล HTML จากเนื้อหาที่เขียน ไม่มีการแนบไฟล์ใน Community รอบนี้
- ถูกใจ/เลิกถูกใจ บันทึก/เลิกบันทึก แสดงยอดตั้งต้นสมมติรวมการกดของผู้ใช้ในเครื่องนี้
- รายละเอียดกระทู้ ความคิดเห็น และการเข้าร่วมกลุ่มจากหน้ากระทู้
- แก้ไขเฉพาะกระทู้ที่เขียนเอง มีวันแก้ไขและตรวจรุ่นข้อมูลเพื่อป้องกันแก้ทับจากแท็บเก่า
- รุ่นแก้ไขใช้เวลาที่เพิ่มขึ้นเสมอ แม้การแก้ไขเกิดในมิลลิวินาทีเดียวกัน
- นำกระทู้หรือความคิดเห็นของตัวเองออกได้ และกู้กลับได้ ไม่ลบเนื้อหาของสมาชิกสมมติรายอื่น
- ซ่อนโพสต์จากฟีด โดยไม่ลบกระทู้หรือยกเลิกการบันทึกโพสต์ จัดการและแสดงกลับในรายการของฉัน
- รายงานกระทู้หรือความคิดเห็น เลือกเหตุผล เพิ่มรายละเอียด และเลือกซ่อนโพสต์ได้
- รายงานมีสถานะชัดเจนว่าอยู่ในเครื่อง ยังไม่ส่งผู้ดูแล ไม่แสดงว่ากำลังมีเจ้าหน้าที่รับเรื่อง
- มีข้อตกลงพื้นที่ร่วมกัน ไม่ดึงข้อมูลกรมธรรม์ ยอดเงิน หรือสุขภาพมาโพสต์เอง

## ข้อมูลและการจัดเก็บ

- seed: กิจกรรม 3 รายการ กระทู้ 3 ความคิดเห็น 1 เข้าร่วมกลุ่มเตรียมเกษียณไว้หนึ่งกลุ่ม
- สมาชิก สถานที่ จำนวนที่นั่งและยอดผู้ร่วมเดิมทั้งหมดเป็นสมมติ
- IndexedDB แยกชื่อ `livera-round3-club` ไม่เปลี่ยนฐานประวัติเบี้ยรอบ 1 หรือแผนเงินรอบ 2
- state ของคลับอ่าน ตรวจรูปแบบ ตรวจเงื่อนไข และเขียนใน readwrite transaction เดียวเพื่อเรียงการเปลี่ยนแปลงจากหลายแท็บ
- hook แจ้งเปลี่ยนข้อมูลผ่าน BroadcastChannel และโหลดใหม่เมื่อกลับมาโฟกัสแท็บ
- ป้องกันกดซ้ำระหว่างบันทึก และไม่แจ้งสำเร็จหาก transaction ล้มเหลว
- ข้อมูลผิดรูปแบบไม่ถูกแทนที่ด้วย seed เงียบ ๆ มีข้อความผิดพลาด ปุ่มลองโหลด และปุ่มคืนค่าคลับแยกพร้อมหน้าตรวจยืนยัน
- คืนค่าคลับล้างเฉพาะข้อมูลรอบ 3 และร่างข้อความของคลับในแท็บนี้ ไม่ล้างเบี้ย แผนเกษียณ หรือการตั้งค่าการแสดงผล
- ไม่มีบริการเซิร์ฟเวอร์ ไม่มีการซิงก์ข้ามอุปกรณ์หรือส่งข้อความถึงคนอื่น ไม่มีการเชื่อมผู้จัด/ผู้ดูแลจริง

นี่เป็นต้นแบบการใช้งาน Community การตรวจสิทธิ์ลูกค้าด้วยระบบสมาชิกจริง การควบคุมสิทธิ์ฝั่งเซิร์ฟเวอร์ การกลั่นกรอง/ตอบรายงานและการยืนยันที่นั่งจากผู้จัดเป็นงานระบบจริงที่ยังไม่รวมในรอบนี้ หน้าต้นแบบระบุว่าเป็นการทดลองในเบราว์เซอร์เสมอ

## การเข้าถึงและหน้าตา

- รูปสมจริงของคนในบ้านพักและกิจกรรม ใช้ asset ที่อยู่ในโปรเจกต์ พร้อมป้ายภาพจำลอง AI
- การ์ดกิจกรรม วันเดือน รูปปก ฟีด วงสนทนา และสถานะถูกใจ/บันทึกที่ตอบสนองต่อการกด
- รองรับตัวอักษรใหญ่ และลดการเคลื่อนไหวตามระบบ
- มือถือกลุ่มสนทนาเลื่อนในแนวนอนเฉพาะแถว ไม่ทำให้หน้าเว็บล้นทั้งหน้า
- ปุ่มที่กำลังเขียนข้อมูลถูกปิดชั่วคราว หน้าต่างไม่ปิดกลางการบันทึก

## ปฏิทิน

ใช้โครงสร้าง iCalendar ตาม RFC 5545: CRLF, UID, DTSTAMP, DTSTART/DTEND ใน UTC, ข้อความ escape และพับบรรทัดไม่เกิน 75 UTF-8 octets โดยไม่ตัดตัวอักษรกลาง byte มี STATUS:TENTATIVE และไม่ส่งอีเมลคำเชิญ

อ้างอิงตรวจ 11 พฤศจิกายน 2569: https://www.rfc-editor.org/rfc/rfc5545

## ตรวจสอบก่อนเผยแพร่

Unit tests รวม 45 กรณี: 28 เดิม + 17 กติกาคลับและ Community ครอบคลุมที่นั่ง การลงทะเบียนซ้ำ เวลาปิดรับ สมาชิกกลุ่ม การจัดการเฉพาะข้อความตัวเอง รายการซ้ำ รุ่นแก้ไข การกู้คืน ซ่อน/บันทึก/รายงาน ค้นหา และปฏิทิน

UI ที่ทดสอบ:

- กรองออนไลน์ ลงทะเบียน 2 ที่นั่ง ตรวจยืนยัน และรีเฟรชแล้วยังมีใบรายการ
- ดาวน์โหลดไฟล์ปฏิทินและตรวจเวลา UTC, UTF-8 และการพับบรรทัด
- เปิดหน้าเตรียมห้องออนไลน์ ยกเลิกพร้อมข้อความเรื่องปฏิทิน
- สร้างกระทู้ เก็บร่างเมื่อปิดหน้าต่าง ดูตัวอย่างและบันทึก
- ถูกใจ บันทึกโพสต์ แสดงความคิดเห็น แล้วรีเฟรชยังอยู่
- `<b>…</b>` แสดงเป็นข้อความธรรมดา ไม่เกิด HTML element ในเนื้อหา
- แก้ไขกระทู้ ถอน/คืนความคิดเห็น นำกระทู้ออก/กู้คืน และรายงานพร้อมซ่อน
- รายงานแสดงในรายการของฉันว่าไม่ได้ส่งผู้ดูแล
- หน้า event list, รายละเอียด, กิจกรรมเต็ม, Community, กระทู้และรายการส่วนตัวไม่ล้นที่ 360 พิกเซล
- หน้าที่ทดสอบพร้อมตัวอักษรใหญ่ 19px ไม่ล้นที่ 360 พิกเซล

ตรวจเพิ่ม: ค้นหาคำว่าสีน้ำและเข้าร่วมกลุ่มจากฟีด เปิดกระทู้สมาชิกสมมติแล้วไม่มีปุ่มแก้ไขของเจ้าของคนอื่น ปุ่มกิจกรรมเต็มถูกปิด และคืนค่าคลับแล้วกระทู้กลับเป็น 3 รายการ ข้อมูลสรุปเบี้ยก่อน/หลังคืนค่าตรงกัน
