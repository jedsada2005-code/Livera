# LIVERA — Round 0 Prototype

โครงเว็บแอปเตรียมชีวิตเกษียณ ธีมแดง–น้ำเงิน ออกแบบให้ใช้งานได้บนมือถือและคอมพิวเตอร์

**รอบนี้คือโครงแอปและข้อมูลสาธิต** ข้อมูลสมาชิก กรมธรรม์ จำนวนเงิน กิจกรรม และกำหนดเวลาทั้งหมดเป็นข้อมูลสมมติ ไม่ใช่ข้อเสนอประกันหรือบริการที่เปิดให้ทำรายการจริง

## สิ่งที่ทดลองได้ในรอบ 0

- เมนูหลัก 5 ส่วน: ภาพรวม / กรมธรรม์ / แผนเกษียณ / คลับ / บริการ
- Dashboard และรายการกรมธรรม์จากข้อมูลตัวอย่างชุดเดียวกัน
- เปิดดูสรุปกรมธรรม์ตัวอย่าง 3 ฉบับ
- โครง Goal จ่ายเบี้ยและแผนเกษียณ พร้อมคำอธิบายรอบที่จะเพิ่มฟังก์ชัน
- กรองกิจกรรมคลับเป็นพบกันจริงและออนไลน์ พร้อมเปิดรายละเอียดตัวอย่าง
- ดูแนวทางบริการสุขภาพแบบนัดส่วนตัว ทบทวนความคุ้มครอง ความรู้ และบริการดูแล
- เปิดศูนย์แจ้งเตือนตัวอย่าง
- ซ่อน/แสดงยอดเงิน ปรับตัวอักษรใหญ่ และคืนค่าการสาธิต
- เก็บเฉพาะการตั้งค่าการแสดงผลในเบราว์เซอร์ เครื่องที่ปิดกั้นการจัดเก็บยังเปิดตัวอย่างได้

ยังไม่มีการบันทึกเบี้ยจริง การรับชำระ การส่งไฟล์ขึ้นระบบ การยืนยันกรมธรรม์ การคำนวณแผนเฉพาะบุคคล การจองกิจกรรมจริง หรือการนัดแพทย์จริง ปุ่มของฟังก์ชันรอบถัดไปเปิดคำอธิบายแทนการทำรายการ

## เปิดในเครื่อง

ใช้ Node.js 24 LTS และ npm จากนั้นรันที่โฟลเดอร์โครงการ:

```sh
npm ci
npm run dev
```

เปิด URL ที่แสดงในหน้าต่างรันโครงการ

## ตรวจและสร้างไฟล์เผยแพร่

```sh
npm run check
npm run build
npm run preview
```

ไฟล์เว็บที่พร้อมเผยแพร่อยู่ใน `dist/` ฟอนต์ไทยถูกบรรจุในไฟล์เว็บ ไม่ต้องเรียก Google Fonts ขณะใช้งาน

## GitHub Pages

โครงการนี้เตรียม workflow ไว้ใน `.github/workflows/pages.yml`:

1. นำไฟล์โครงการขึ้น branch `main` ที่ราก repository
2. ที่ Settings → Pages → Build and deployment เลือก Source เป็น **GitHub Actions**
3. workflow จะติดตั้งจาก lockfile ตรวจ TypeScript สร้างเว็บ และเผยแพร่ไฟล์ `dist/`
4. Pull request จะตรวจการสร้างเว็บโดยไม่เผยแพร่

ใช้ relative asset base และ hash navigation เพื่อให้เปิดได้ทั้งรากเว็บไซต์และภายใต้ชื่อ repository เช่น `/Livera/#/policies` โดยรีเฟรชหน้าภายในได้

เมื่อเผยแพร่สำเร็จ URL ของโครงการนี้คือ `https://jedsada2005-code.github.io/Livera/` ต้องดูสถานะงานในแท็บ Actions ก่อนถือว่าลิงก์พร้อมใช้งาน

## โครงสร้าง

```text
src/
  App.tsx                 โครงแอป 5 หน้าและหน้าต่างสาธิต
  components/ui.tsx       รูปแบบร่วม ปุ่ม ป้ายสถานะ หน้าต่าง และภาพประกอบ
  data/demo.ts            ข้อมูลสมมติและยอดรวมที่คำนวณจากชุดเดียวกัน
  hooks/usePreferences.ts การตั้งค่าการแสดงผลในเบราว์เซอร์
  routing.ts              เส้นทางหน้าจอสำหรับ static hosting
  main.tsx                จุดเริ่มและฟอนต์ไทย
  styles.css              ธีม รูปแบบมือถือ/คอมพิวเตอร์ และการเข้าถึง
public/
  favicon.svg             สัญลักษณ์ของ Prototype
.github/workflows/
  pages.yml               การตรวจและเผยแพร่ GitHub Pages
docs/
  ROUND_0.md              ขอบเขตและรายการตรวจรอบนี้
```

## ลำดับถัดไป

รอบ 1 เพิ่มรายละเอียดกรมธรรม์ ประวัติ และการบันทึกเบี้ยพร้อมสถานะหลักฐาน โดยให้ยอดสัมพันธ์กันทุกหน้า รอบ 2 เพิ่ม Goal และเครื่องคำนวณที่รับข้อมูลจริงในโหมดสาธิต รอบ 3 คลับและชุมชน รอบ 4 คำขอบริการส่วนตัว รอบ 5 ข่าว คลิป และบัญชี

ก่อนเชื่อมบริการจริง ต้องเพิ่มระบบสมาชิก การจัดเก็บข้อมูลส่วนกลาง สิทธิผู้ใช้ และคู่ค้าที่เกี่ยวข้องแยกจาก Prototype นี้
