# LIVERA — Round 2 Prototype

แอปเตรียมชีวิตเกษียณ ธีมแดง–น้ำเงิน สำหรับทดลองบนมือถือและคอมพิวเตอร์

**[เปิดแอปออนไลน์](https://jedsada2005-code.github.io/Livera/?v=0.2.0)**

ข้อมูลสมาชิก กรมธรรม์ จำนวนเงิน กิจกรรม และรูปสถานที่เป็นข้อมูลหรือภาพสมมติสำหรับ Prototype ไม่มีธุรกรรมหรือการเชื่อมบริษัทประกันจริง

## รอบที่ 2 เพิ่มอะไร

- Goal ออมให้พอจ่ายเบี้ย เชื่อมงวดถัดไปกับประวัติจากรอบ 1
- ระบุเงินที่กันไว้ ดูยอดที่ยังขาด ตารางแบ่งออม และบันทึกเป้าหมายแต่ละงวด
- เครื่องคำนวณเกษียณที่ปรับอายุ รายจ่าย เงินเฟ้อ เงินออม ผลตอบแทน และช่วงรับรายได้ได้
- ผลเงินก้อน เงินที่คาดว่าสะสมได้ ส่วนขาด และเงินออมรายเดือนที่ต้องใส่รวม/เพิ่ม
- กราฟเงินคงเหลือ ตารางรายปี เปรียบเทียบแผน และปุ่มลองสถานการณ์
- บันทึกแผนในเบราว์เซอร์ ดาวน์โหลด CSV และล้างเฉพาะแผนเงิน
- ปิดผล/ช่องกรอกเมื่อซ่อนยอด ป้องกันบันทึกผลเก่าที่ยังไม่คำนวณหลังแก้ไข

เปิดตรงได้ที่ [Goal](https://jedsada2005-code.github.io/Livera/?v=0.2.0#/retirement/goal) หรือ [เครื่องคำนวณ](https://jedsada2005-code.github.io/Livera/?v=0.2.0#/retirement/calculator) รายละเอียดสูตรและขอบเขตใน `docs/ROUND_2.md`

## รอบที่ 1 เพิ่มอะไร

- รายละเอียดรายกรมธรรม์ ประวัติ ความคุ้มครอง ผู้รับผลประโยชน์ และหมวดเอกสาร
- ค้นหา/กรองกรมธรรม์ และกรองประวัติตามสถานะ
- บันทึกการจ่ายบางส่วนหรือเต็มงวด ผ่านหน้ากรอก ตรวจสรุป และผลสำเร็จ
- แนบรูปหรือ PDF ได้ครั้งละหนึ่งไฟล์ไม่เกิน 5 MB มีไฟล์สาธิตเตรียมไว้ให้
- เก็บรายการและหลักฐานในเบราว์เซอร์ เมื่อรีเฟรชยังเปิดดูได้
- ยอดใน Dashboard และรายละเอียดสัมพันธ์กับรายการที่บันทึก
- ป้องกันบันทึกซ้ำ ยอดเกินงวด และข้อมูลจากอีกแท็บที่เปลี่ยนไปแล้ว
- ยกเลิกบันทึกพร้อมเหตุผล รักษาประวัติและไฟล์ แล้วคืนยอดอย่างถูกต้อง
- ภาพสมจริงของผู้สูงอายุในบ้านพักและกิจกรรมคลับ พร้อมภาพหน้าแรกแบบสลับได้
- วงความคืบหน้า การเปลี่ยนหน้า/แท็บนุ่มนวล การ์ดตอบสนอง และหน้าบันทึกสำเร็จ
- รองรับลดการเคลื่อนไหว ตัวอักษรใหญ่ ซ่อนยอด และคืนข้อมูลสาธิต

## ทดลองใช้งาน

1. เปิดภาพรวมหรือกรมธรรม์ แล้วกด “บันทึกการชำระ”
2. เลือกงวด วันที่ และยอด เช่น บันทึก 3,000 จากเบี้ย 10,000 บาท
3. เลือกไฟล์ตัวอย่างหรือใช้ไฟล์สาธิตที่มีให้ แล้วตรวจสรุปและยืนยัน
4. ดูประวัติและยอดล่าสุด จากนั้นลองบันทึกส่วนที่เหลือ 7,000 บาท
5. เปิดดูหลักฐานหรือยกเลิกบันทึกที่เพิ่ม พร้อมระบุเหตุผล
6. หากต้องเริ่มใหม่ ไปที่บัญชี → คืนค่าประวัติสาธิต

ไม่แนบหลักฐานจะแสดง “ผู้ใช้บันทึก” แนบแล้วแสดง “รอตรวจหลักฐาน” ทั้งสองสถานะยังไม่ใช่การยืนยันรับเงินจากบริษัทประกัน การยกเลิกบันทึกไม่ใช่การคืนเงินหรือยกเลิกกรมธรรม์

## การจัดเก็บ

รายการและไฟล์อยู่ใน IndexedDB ของเบราว์เซอร์นี้ ไม่มีเซิร์ฟเวอร์รับข้อมูล ไม่ซิงก์ข้ามอุปกรณ์ และอาจถูกล้างตามการจัดการพื้นที่ของเบราว์เซอร์ ใช้ข้อมูลและไฟล์สาธิตเท่านั้น

ร่างข้อความเก็บชั่วคราวในแท็บ เมื่อปิดก่อนบันทึกต้องแนบไฟล์ใหม่ แผนเงินรอบ 2 ที่กดบันทึกและการตั้งค่าการแสดงผลเก็บใน localStorage หากจัดเก็บรายการไม่ได้ แอปแสดงข้อความและปิดการบันทึกแทนการแจ้งสำเร็จโดยไม่เก็บข้อมูล

## เปิดและตรวจในเครื่อง

ใช้ Node.js 24 LTS:

```sh
npm ci
npm run dev
```

เปิด URL ที่แสดงจากคำสั่ง ไม่เปิดไฟล์ index.html ต้นฉบับโดยตรง

```sh
npm test
npm run build
npm run preview
```

การทดสอบแบบ unit ครอบคลุมกติกาเงิน งวด วัน สถานะ รายการซ้ำ และการยกเลิก ส่วนการทดสอบ UI และข้อจำกัดระบุใน `docs/ROUND_1.md` และ `docs/ROUND_2.md`

## GitHub Pages

ที่ Settings → Pages ให้เลือก Source เป็น **GitHub Actions** workflow ใน `.github/workflows/pages.yml` จะติดตั้งจาก lockfile ทดสอบ ตรวจ TypeScript สร้างเว็บ และเผยแพร่ `dist/` เมื่อ push ไป `main` ส่วน pull request จะตรวจโดยไม่เผยแพร่

ใช้ relative asset base และ hash navigation เช่น `/Livera/#/policies/saving` เพื่อรีเฟรชหน้ารายละเอียดบน static hosting ได้ รูปและฟอนต์บรรจุอยู่กับโครงการ

