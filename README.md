## รอบ 11: ภาพรวม NVL

**[เปิดหน้าภาพรวม](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/overview)**

- เพิ่มกราฟเส้นติดตามเงินสะสมสุทธิในแผนเกษียณ (NVL) เลือกดู 6 เดือน 1 ปี หรือทั้งหมด
- เพิ่มแถบเป้าหมายทรงสี่เหลี่ยม แสดงยอดปัจจุบัน เป้าหมาย ร้อยละความสำเร็จ และยอดที่ยังขาด
- ปรับหน้ามือถือให้ใช้แถบแนวนอนเพื่ออ่านง่ายและไม่เพิ่มความยาวหน้าเกินจำเป็น
- ปุ่มดูที่มาของยอดอธิบายองค์ประกอบและข้อจำกัดของข้อมูลตัวอย่าง
- เปลี่ยนบัญชีตัวอย่างเป็น **พีระ อารมณ์ดี** และรองรับโหมดซ่อนยอด/ตัวอักษรใหญ่

ตัวเลข NVL ใน Prototype เป็นข้อมูลสมมติสำหรับทดลองหน้าจอ ยังไม่เชื่อมบัญชี กรมธรรม์ หรือกองทุนจริง

## รอบ 10: ฟีดข่าวและ Reels

**[เปิดฟีดข่าว](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/knowledge/news)** · **[เปิด Reels](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/knowledge/reels)** · **[คลังของฉัน](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/knowledge/saved)**

- ฟีดคัดสรร 6 ข่าว/บทความ แสดงครั้งละ 3 เรื่อง ค้นหา กรองหัวข้อ/รูปแบบ และเรียงตามความสนใจหรือวันที่เผยแพร่
- Reels แนวตั้ง 4 คลิป เลื่อนทีละเรื่อง เล่น/หยุด เลื่อนเวลา เปิดเสียงและคำบรรยาย อ่านสคริปต์ และดูต่อจากตำแหน่งเดิม
- 2 คลิปใหม่มีเสียงสังเคราะห์ภาษาไทย คลิปเดิม 2 เรื่องเป็นข้อความไม่มีเสียง ทุกคลิปมีคำบรรยายและแหล่งอ้างอิง
- บันทึกเรื่อง ประวัติอ่าน คลังดูต่อ คัดลอกลิงก์ และเปิดเครื่องมือวางแผนที่เกี่ยวข้อง
- มือถือย่อส่วนหัวและพับตัวกรอง/รายละเอียดรอง มีโหมดตัวอักษรใหญ่และปุ่มควบคุมคลิปอยู่นอกพื้นที่เลื่อน

ใช้เนื้อหาคัดสรรและบทความ LIVERA พร้อมต้นทางและวันที่ ไม่ใช่บริการข่าวสดอัตโนมัติ ประวัติเดิมยังอยู่ในเบราว์เซอร์เดิม ไม่มีการส่งข้อความให้สมาชิกอื่นจากปุ่มคัดลอกลิงก์

## รอบ 9: รวมเงินปลายทาง

**[เริ่มแผนรวมเงิน](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/retirement/accumulation)** · **[ดูแผนตัวอย่างสมมติ](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/retirement/accumulation/demo)**

- เพิ่มหลายบัญชีจากเงินออม/ลงทุน PVD ประกัน ประกันสังคม และผลประหยัดภาษี สูงสุด 20 รายการ
- จำลองเงิน ณ เกษียณ รายรับตามงวด เงินตั้งต้นที่ต้องมี ส่วนขาด และยอดออมเพิ่มต่อเดือน
- PVD แยกส่วนลูกจ้าง/นายจ้าง สิทธิ และเงินกันภาษี ประกันใช้ตารางรับ/จ่ายตามเดือนและแยกเวนคืนออกจากผลครบสัญญา
- เชื่อมสำเนางบที่พักรอบ 8 ตรวจปีราคา และต้องระบุค่าที่พักหลังจบช่วงงบหากอายุปลายแผนยาวกว่า
- แสดงเหตุผลที่นับ/ไม่นับแต่ละแหล่ง เตือนงวดสภาพคล่องก่อนเกษียณ เปิดกราฟ/ตารางรายปี และดาวน์โหลด CSV พร้อมสมมติฐาน
- มีแผนตัวอย่างคำนวณจาก 5 แหล่งเงินแบบอ่านอย่างเดียว ไม่ทับข้อมูลผู้ใช้ มือถือแสดงยอดหลักก่อนและเปิดรายละเอียดเพิ่มได้

ทุกยอดเป็นข้อมูลหรือสมมติฐานที่ผู้ใช้ระบุ ไม่มีการคำนวณสิทธิประกันสังคม ภาษี หรือสิทธิ PVD ตามกฎหมายอัตโนมัติ ผลยังไม่สรุปส่วนขาดเมื่อข้อมูลที่จำเป็นไม่ครบ ไม่มีการนำรายรับหลายปีบวกเป็นเงินก้อนทันที หรือใช้เบี้ยสะสมแทนเงินประกันที่จะได้รับ

แผนรอบ 9 เก็บแยกจากข้อมูลเดิม ดึงข้อมูลตั้งต้นได้โดยไม่แก้ทับรายละเอียดที่เติมในแผนนี้แล้ว ลิงก์เดิม `#/retirement/future/...` ยังเปิดข้อมูลรอบ 6–8 ได้ เมนูเงินปลายทางหลักเปิดเครื่องรวมเงินรอบ 9

รายละเอียดสูตร/ขอบเขต/ผลตรวจ: [docs/ROUND_9.md](docs/ROUND_9.md)

## รอบ 8: ที่พักและงบ 5–20 ปี

**[ค้นหาที่พัก](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/explore)** · **[งบที่บันทึก](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/explore/housing/budgets)**

- Jin Wellbeing County และ The Aspen Tree พร้อมภาพถ่ายจริงจากโครงการ ค้นหาชื่อ/ทำเล กรองประเภท และบันทึกสถานที่
- รายละเอียดแยกรู้จักสถานที่ รูปแบบสิทธิ/ค่าใช้จ่าย และคำถามก่อนตัดสินใจ
- เครื่องทำงบ 5–20 ปี: รายเดือน รายปี ซื้อกรรมสิทธิ์ หรือสิทธิพักอาศัย/เช่าระยะยาว ตามวิธีจ่ายที่ผู้ใช้ต้องการจำลอง
- แยกเงินก้อนแรก ยอดประจำ ค่าดูแลต่อคน ค่าใช้จ่ายอื่น เงินประกันคืนได้ และสมมติฐานขึ้นราคา
- ลองเทียบ 5/10/15/20 ปี เปิดตารางจ่ายรายปี บันทึกงบล่าสุดต่อสถานที่ และนำสำเนางบไปแผนปลายทาง
- เป้าหมายเปลี่ยนจะแสดงเตือนว่างบเดิมยังไม่ตรง รองรับซ่อนยอด/ตัวอักษรใหญ่ และเก็บตารางกับรายละเอียดรองไว้ในเมนูเปิดเพิ่ม

ราคาแพ็กเกจปัจจุบันยังรอใบเสนอราคาที่มีรายละเอียดครบ ผลคำนวณทั้งหมดจึงเป็นงบจากสมมติฐานที่ผู้ใช้กรอก ไม่ใช่ราคาเสนอขายจากโครงการ เครื่องรวมเงินออมและส่วนที่ขาดจากหลายแหล่งเพิ่มแล้วในรอบ 9

## รอบ 7: ค้นหาและเปรียบเทียบประกัน

**[ค้นหาแผนประกัน](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/policies/discover)** · **[แผนที่บันทึก](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/policies/discover/saved)** · **[เปรียบเทียบ](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/policies/discover/compare)**

- แผนสะสมทรัพย์จริง 6 รายการจาก AIA และเมืองไทยประกันชีวิต พร้อมโลโก้และลิงก์ต้นทาง
- ค้นหาชื่อ/คำใกล้เคียง กรองบริษัท ช่วงอายุ ระยะจ่ายเบี้ย และระยะคุ้มครอง
- รายละเอียดแยกภาพรวม เงินคืน/ครบสัญญา และเงื่อนไข พร้อมวันที่ตรวจแหล่งอ้างอิง
- บันทึกแผน เปรียบเทียบ 2–3 แผนด้วยอายุ งบเบี้ยรายปี และทุนประกันเป้าหมายชุดเดียวกัน
- ส่งรายการที่สนใจไปสรุปเส้นทางเงินปลายทางได้ โดยไม่เพิ่มเป็นสินทรัพย์หรือกรมธรรม์ที่ซื้อแล้ว
- มือถือแสดง 3 แผนต่อหน้า ตัวกรองอยู่ในกล่องเปิดเพิ่ม รองรับซ่อนข้อมูลส่วนตัวและตัวอักษรใหญ่

เบี้ยเฉพาะบุคคล มูลค่าเวนคืน และผลตอบแทนสุทธิยังรอใบเสนอราคา งบที่กรอกจึงยังใช้ยืนยันความสามารถในการซื้อไม่ได้ รายชื่อบริษัทและโลโก้เป็นข้อมูลอ้างอิงสาธารณะ ยังไม่ยืนยันสถานะคู่สัญญากับ LIVERA

รายละเอียดและผลตรวจ: [docs/ROUND_7.md](docs/ROUND_7.md) · แหล่งผลิตภัณฑ์และโลโก้: [docs/ROUND_7_SOURCES.md](docs/ROUND_7_SOURCES.md)

- Community: กลุ่มสนทนา กระทู้ ความคิดเห็น ถูกใจ บันทึกโพสต์ และค้นหา
- เก็บร่าง แก้ไขข้อความตัวเอง นำออกและกู้คืนได้
- ซ่อน/รายงานเนื้อหา พร้อมสถานะว่าเป็นรายงานสาธิตในเครื่อง
- รายการของฉันรวมกิจกรรม โพสต์ที่บันทึก กระทู้ของฉัน โพสต์ที่ซ่อน และรายงาน
- เก็บข้อมูลใน IndexedDB แยกจากประวัติเบี้ยและแผนเงิน มีปุ่มคืนค่าคลับแยก

## รอบที่ 2 เพิ่มอะไร

- Goal ออมให้พอจ่ายเบี้ย เชื่อมงวดถัดไปกับประวัติจากรอบ 1
- ระบุเงินที่กันไว้ ดูยอดที่ยังขาด ตารางแบ่งออม และบันทึกเป้าหมายแต่ละงวด
- เครื่องคำนวณเกษียณที่ปรับอายุ รายจ่าย เงินเฟ้อ เงินออม ผลตอบแทน และช่วงรับรายได้ได้
- ผลเงินก้อน เงินที่คาดว่าสะสมได้ ส่วนขาด และเงินออมรายเดือนที่ต้องใส่รวม/เพิ่ม
- กราฟเงินคงเหลือ ตารางรายปี เปรียบเทียบแผน และปุ่มลองสถานการณ์
- บันทึกแผนในเบราว์เซอร์ ดาวน์โหลด CSV และล้างเฉพาะแผนเงิน
- ปิดผล/ช่องกรอกเมื่อซ่อนยอด ป้องกันบันทึกผลเก่าที่ยังไม่คำนวณหลังแก้ไข

เปิดตรงได้ที่ [Goal](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/retirement/goal) หรือ [เครื่องคำนวณ](https://jedsada2005-code.github.io/Livera/?v=0.11.1#/retirement/calculator) รายละเอียดสูตรและขอบเขตใน `docs/ROUND_2.md`

## รอบที่ 1 เพิ่มอะไร

- รายละเอียดรายกรมธรรม์ ประวัติ ความคุ้มครอง ผู้รับผลประโยชน์ และหมวดเอกสาร
- ค้นหา/กรองกรมธรรม์ และกรองประวัติตามสถานะ
- บันทึกการจ่ายบางส่วนหรือเต็มงวด ผ่านหน้ากรอก ตรวจสรุป และผลสำเร็จ
- แนบรูปหรือ PDF ได้ครั้งละหนึ่งไฟล์ไม่เกิน 5 MB มีไฟล์สาธิตเตรียมไว้ให้
- เก็บรายการและหลักฐานในเบราว์เซอร์ เมื่อรีเฟรชยังเปิดดูได้
- ยอดใน Dashboard และรายละเอียดสัมพันธ์กับรายการที่บันทึก
- ป้องกันบันทึกซ้ำ ยอดเกินงวด และข้อมูลจากอีกแท็บที่เปลี่ยนไปแล้ว
- ยกเลิกบันทึกพร้อมเหตุผล รักษาประวัติและไฟล์ แล้วคืนยอดอย่างถูกต้อง
- ภาพสมจริงของผู้สูงอายุในบ้านพักและกิจกรรมคลับ พร้อมภาพหน้าแรกแบบสลับได้
- วงความคืบหน้า การเปลี่ยนหน้า/แท็บนุ่มนวล การ์ดตอบสนอง และหน้าบันทึกสำเร็จ
- รองรับลดการเคลื่อนไหว ตัวอักษรใหญ่ ซ่อนยอด และคืนข้อมูลสาธิต

## ทดลองใช้งาน

1. เปิดภาพรวมหรือกรมธรรม์ แล้วกด “บันทึกการชำระ”
2. เลือกงวด วันที่ และยอด เช่น บันทึก 3,000 จากเบี้ย 10,000 บาท
3. เลือกไฟล์ตัวอย่างหรือใช้ไฟล์สาธิตที่มีให้ แล้วตรวจสรุปและยืนยัน
4. ดูประวัติและยอดล่าสุด จากนั้นลองบันทึกส่วนที่เหลือ 7,000 บาท
5. เปิดดูหลักฐานหรือยกเลิกบันทึกที่เพิ่ม พร้อมระบุเหตุผล
6. หากต้องเริ่มใหม่ ไปที่บัญชี → คืนค่าประวัติสาธิต

ไม่แนบหลักฐานจะแสดง “ผู้ใช้บันทึก” แนบแล้วแสดง “รอตรวจหลักฐาน” ทั้งสองสถานะยังไม่ใช่การยืนยันรับเงินจากบริษัทประกัน การยกเลิกบันทึกไม่ใช่การคืนเงินหรือยกเลิกกรมธรรม์

## การจัดเก็บ

รายการและไฟล์อยู่ใน IndexedDB ของเบราว์เซอร์นี้ ไม่มีเซิร์ฟเวอร์รับข้อมูล ไม่ซิงก์ข้ามอุปกรณ์ และอาจถูกล้างตามการจัดการพื้นที่ของเบราว์เซอร์ ใช้ข้อมูลและไฟล์สาธิตเท่านั้น

ร่างข้อความเก็บชั่วคราวในแท็บ เมื่อปิดก่อนบันทึกต้องแนบไฟล์ใหม่ แผนเงินรอบ 2 ที่กดบันทึกและการตั้งค่าการแสดงผลเก็บใน localStorage หากจัดเก็บรายการไม่ได้ แอปแสดงข้อความและปิดการบันทึกแทนการแจ้งสำเร็จโดยไม่เก็บข้อมูล

## เปิดและตรวจในเครื่อง

ใช้ Node.js 24 LTS:

```sh
npm ci
npm run dev
```

เปิด URL ที่แสดงจากคำสั่ง ไม่เปิดไฟล์ index.html ต้นฉบับโดยตรง

```sh
npm test
npm run build
npm run preview
```

การทดสอบแบบ unit ครอบคลุมกติกาเงิน งวด วัน สถานะ รายการซ้ำ และการยกเลิก ส่วนการทดสอบ UI และข้อจำกัดระบุใน `docs/ROUND_1.md` และ `docs/ROUND_2.md`, `docs/ROUND_3.md`, `docs/ROUND_4.md`

## GitHub Pages

ที่ Settings → Pages ให้เลือก Source เป็น **GitHub Actions** workflow ใน `.github/workflows/pages.yml` จะติดตั้งจาก lockfile ทดสอบ ตรวจ TypeScript สร้างเว็บ และเผยแพร่ `dist/` เมื่อ push ไป `main` ส่วน pull request จะตรวจโดยไม่เผยแพร่

ใช้ relative asset base และ hash navigation เช่น `/Livera/#/policies/saving` เพื่อรีเฟรชหน้ารายละเอียดบน static hosting ได้ รูปและฟอนต์บรรจุอยู่กับโครงการ
